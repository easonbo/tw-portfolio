# 我的台股持股（tw-portfolio）

每天自動更新上市櫃收盤價、加權指數、櫃買指數，在網頁上算每日損益與累積損益。

- **交易紀錄只存在你的瀏覽器**（localStorage），repo 公開也看不到你的持股。
- GitHub Actions 每個交易日台灣時間 15:17 與 18:47 抓收盤資料（第二次補抓櫃買較晚公布的資料）。
- 網頁開著時，15:00–20:00 每 30 分鐘自動重抓一次。

## 一次性設定（約 5 分鐘）

1. 在 GitHub 新建 repo，名稱例如 `tw-portfolio`（Public，Pages 免費）。
2. 把這個資料夾的所有檔案上傳（含 `.github/workflows/update.yml`；網頁上傳時隱藏資料夾要整個拖進去）。
3. **Settings → Actions → General → Workflow permissions** 選 **Read and write permissions** → Save。
4. **Settings → Pages → Source** 選 **Deploy from a branch**，Branch 選 `main` / `(root)` → Save。
5. **Actions → 更新台股收盤資料 → Run workflow**，`start` 填你第一筆交易的日期（例如 `2026-01-02`）。
   - 每個交易日約 10 秒（證交所有頻率限制），回補一年約 40–50 分鐘，跑完會自動 commit。
6. 打開 `https://<你的帳號>.github.io/tw-portfolio/`，到「交易紀錄」新增交易，或在「設定與備份」用 CSV 批次匯入。

## 損益怎麼算

| 項目 | 算法 |
|---|---|
| 當日損益 | 今日市值 − 昨日市值 − 今日淨投入（買進付出 − 賣出收回 − 股利） |
| 當日報酬 | 當日損益 ÷（昨日市值 + 今日買進金額） |
| 累積報酬 | 每日報酬連乘（時間加權），加減碼不會扭曲報酬率，可直接跟大盤比 |
| 均價 / 未實現 | 平均成本法，均價含買進手續費 |
| 已實現 | 賣出淨收入（扣手續費、證交稅）− 賣出股數 × 均價，加上現金股利 |
| 手續費 | 成交金額 × 0.1425% × 折數，無條件捨去，最低 20 元（設定頁可改） |
| 證交稅 | 股票 0.3%、ETF（00 開頭）0.1%、債券 ETF（00…B）0%，可在設定頁改 |

累積損益 ＝ 已實現 ＋ 未實現，兩邊一定對得起來。

**除權息**：資料是未還原的收盤價，除息日股價會掉。請在**除息日**記一筆「現金股利」（金額填實際入帳數），除權日記「股票股利」（填配到的股數），當天損益才不會失真。

## 檔案

```
index.html                     網頁（全部前端邏輯）
scripts/update.py              抓資料：證交所 MI_INDEX、櫃買每日收盤行情、櫃買指數（失敗改用 Yahoo）
.github/workflows/update.yml   排程與手動回補
data/stocks/<代號>.json         每檔股票的每日收盤價（自動產生）
data/index.json                每日加權、櫃買指數（自動產生）
data/names.json, meta.json     代號名稱清單、最後更新時間（自動產生）
```

## 疑難排解

- **Actions 紅燈**：點進去看 log，會列出哪天哪個市場抓失敗。證交所偶爾擋 GitHub 的 IP，隔天重跑通常就好。
- **某檔顯示「無資料」**：代號打錯，或是那檔不在上市櫃收盤行情內（例如興櫃）。
- **換電腦 / 手機**：設定頁「匯出 JSON」→ 在新裝置「匯入 JSON」。
